# PIVOT & QUEST コーポレートサイト

静的HTML/CSSのサイトです。`index.html` がトップページで、既存の学校向け・進路マップ・規約ページも同じディレクトリにあります。

## ローカル確認

```powershell
cd C:\dev\p-quest-corp
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザーで http://127.0.0.1:8765/ を開きます。ビルドや依存パッケージのインストールは不要です。

## 本番公開

GitHubの `main` をVercelプロジェクト `p-quest_corp` に連携し、`https://p-quest.com/` に公開します。

`vercel.json` の `outputDirectory` は `.` に固定しています。未指定の場合、素材用の `public/` がVercelの公開ルートに自動選択され、ルート直下のHTMLが含まれず404になります。HTMLとCSSの配置を変えず、`/public/assets/drive/` の画像パスも保つための設定です。
