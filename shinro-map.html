Inquiry Map

興味・問いから、
学問と進路へ。

進路は「偏差値でどこに入れるか」ではなく、「なぜ、何を学ぶのか」から考えられます。あなたの好き・違和感・経験を出発点に、そこから立ち上がる問いが、どんな学問や仕事へ広がっていくのか。進路選びの段階で使える、PIVOT&QUEST独自の地図です。

1自分に近い「領域」を見つける
2心が動く「問い」を選ぶ
3その先の学問・進路を見る
言葉・歴史・文化Language / Culture
物語や言葉に、心が動く
人はなぜ、言葉で世界を捉えるのか？
文学・言語学・哲学 → 編集・翻訳・研究・教育
昔の人の暮らしや文化が気になる
いまの社会は、どんな歴史の上にあるのか？
歴史学・文化人類学 → 学芸員・研究・メディア
表現・デザイン・映像が好き
「伝わる表現」は、どう生まれるのか？
芸術・デザイン学 → クリエイター・制作・広告
社会・経済・政治Society / Economy
身近な不公平が、気になる
「良い社会」の仕組みは、どう作れるか？
法学・政治学 → 公務・法律・政策
お金やビジネスの動きに関心
人や企業は、なぜその選択をするのか？
経済学・経営学・商学 → 経営・金融・マーケティング
世界の出来事や、他国の文化
国や文化を超えて協働するには？
国際関係・社会学 → 国際機関・NPO・メディア
ヒト・生命・医療People / Life
人の心のはたらきに、関心がある
人はなぜ、そう感じ、行動するのか？
心理学・人間科学 → 心理職・支援・研究
体や健康、ケアに関わりたい
人が「健やかである」とは何か？
医学・看護・福祉 → 医療・看護・福祉職
教育や、子どもの育ちに関心
学びや育ちは、どう支えられるか？
教育学 → 教員・教育支援・研究
モノ・自然・法則Nature / Technology
仕組みや、モノづくりが好き
どう作れば、人の役に立つのか？
工学・情報学 → 技術開発・エンジニア
自然や環境の法則を知りたい
この現象は、なぜ起きるのか？
理学・環境学 → 研究・環境・技術
食・農・生き物に関わりたい
命や資源を、どう活かし守るか？
農学・水産学 → 研究・生産・環境

各領域を、学問・学部・仕事の例と先輩の声まで掘り下げる｜詳細版を見る →

※ この進路探究マップは PIVOT&QUEST が独自に作成した、進路を「問い」から考えるための一例です。学部・学科・職業の分類を断定するものではなく、実際には一人ひとりの出発点から個別に描いていきます。ここに載っていない領域・進路も数多くあります。

あなただけの一本の線を、一緒に描く。

「自分はどの領域だろう」「問いが浮かばない」——そこからで大丈夫です。総合型選抜対策専門塾 Lighthouse で、あなたの経験を問いに変え、学問と進路へつなぎます。
